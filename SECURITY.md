# Security Policy

Please do not post tokens, credentials, private paths, or other sensitive information in public issues.

Do not upload ROMs, saves, emulator states, BIOS files, generated patched ROMs, or commercial assets — not even to reproduce a bug. Describe the issue in text instead.

For normal translation, terminology, screenshot, textbox, or rendering problems, use GitHub Issues.

For credential leaks, private data exposure, or repository-safety problems, use the most private GitHub contact path available for this repository. If no private reporting channel is available, open a minimal public issue that describes the category of problem without posting the sensitive data itself.

There is no guaranteed response SLA. Reports will be reviewed as maintainer time allows.
