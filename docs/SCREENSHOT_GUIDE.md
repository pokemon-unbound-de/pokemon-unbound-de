# Screenshot Guide

Screenshots are welcome only after manual review.

Use PNG files and place curated images in `docs/screenshots/`.

Suggested names:

- `01_title_or_intro_de.png`
- `02_dialog_de.png`
- `03_menu_de.png`
- `04_mission_log_de.png`
- `05_story_lebelle_de.png`

Before commit:

- Check for private overlays or local paths.
- Avoid emulator menu bars where practical.
- Avoid excessive spoilers.
- Do not upload ROMs, saves, states, BIOS files, or emulator configs.
- Review each image manually.
